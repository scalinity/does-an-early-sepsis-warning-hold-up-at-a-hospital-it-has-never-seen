# Does an early sepsis warning hold up at a hospital it has never seen?

Final project proposal for CAI 5720, Fundamentals of Artificial Intelligence in Medicine I. Canvas group Final Project 6: Karissa Kocourek and Daniel Escalante.

Using only data charted up to a given ICU hour, the project asks whether a model can flag adult ICU patients who will meet Sepsis-3 criteria within the next 6 hours, and whether it stays accurate and calibrated at a hospital it was never trained on. It develops on Beth Israel Deaconess and holds out Emory as an external test site, using the [PhysioNet/Computing in Cardiology Challenge 2019](https://physionet.org/content/challenge-2019/1.0.0/) data, version 1.0.0, under CC BY 4.0.
